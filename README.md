# Task-6-K-Nearest-Neighbors-KNN-Classification
This project applies K-Nearest Neighbors (KNN) classification on the Iris dataset.

## Steps

1. *Data Preprocessing*
   - Load Iris dataset
   - Normalize features using StandardScaler

2. *Model Building*
   - Use KNeighborsClassifier from scikit-learn

3. *Experiments*
   - Evaluate for K = 3, 5, 7
   - Report accuracy and show confusion matrix

4. *Visualization*
   - Plot decision boundaries using first two features

## Requirements

- Python 3.x
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn
